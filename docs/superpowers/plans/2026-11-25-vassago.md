# Vassago Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Vassago, a macOS menu bar app that records what is copied (text, images, files), keeps it on disk, and pastes a picked clip from a list that a hotkey opens at the mouse pointer.

**Architecture:** The history's ordering, limits and launch clean-up, the hotkey rules and version comparison are pure logic in the `VassagoEngine` library, with unit tests. In the app, `Clipboard` watches, reads and writes the clipboard on one background queue and `Store` keeps the files. One observable `AppModel` holds settings and state for the menu bar item, the pop-up list (a native menu) and a SwiftUI panel. Spec: `docs/superpowers/specs/2026-11-25-vassago-design.md`.

**Tech Stack:** Swift 6 toolchain (language mode 5), SwiftPM, AppKit, SwiftUI, Combine, Carbon hotkeys, ImageIO, CryptoKit, ServiceManagement, Swift Testing. No third-party dependencies.

```swift
/// A plain three-number version such as 0.2.0. Anything else is refused rather than guessed at.
public struct Version: Comparable {
    private let parts: [Int]

    /// Accepts "0.2.0" or a release tag "v0.2.0".
    public init?(_ text: String) {
        let bare = text.hasPrefix("v") ? text.dropFirst() : text[...]
        let pieces = bare.split(separator: ".", omittingEmptySubsequences: false)
        let numbers = pieces.compactMap { piece -> Int? in
            piece.allSatisfy { ("0"..."9" as ClosedRange<Character>).contains($0) } ? Int(piece) : nil
        }
        guard pieces.count == 3, numbers.count == 3 else { return nil }
        parts = numbers
    }

    public var text: String {
        parts.map(String.init).joined(separator: ".")
    }

    public static func < (a: Version, b: Version) -> Bool {
        a.parts.lexicographicallyPrecedes(b.parts)
    }
}
```

```swift
/// The modifier keys a shortcut can use.
public struct Modifiers: OptionSet, Hashable {
    public let rawValue: UInt8

    public init(rawValue: UInt8) {
        self.rawValue = rawValue
    }

    public static let control = Modifiers(rawValue: 1)
    public static let option = Modifiers(rawValue: 2)
    public static let shift = Modifiers(rawValue: 4)
    public static let command = Modifiers(rawValue: 8)
}

/// The shortcut that opens the list: modifiers with one key.
public struct Hotkey: Equatable {
    public var modifiers: Modifiers
    /// Virtual key code.
    public var keyCode: UInt16

    public init(modifiers: Modifiers, keyCode: UInt16) {
        self.modifiers = modifiers
        self.keyCode = keyCode
    }

    /// Control + Option + V, the default.
    public static let standard = Hotkey(modifiers: [.control, .option], keyCode: 9)

    /// Control, Option or Command must be held, and Command+Tab stays with the app switcher.
    public var isValid: Bool {
        if keyCode == 48, modifiers.contains(.command) { return false }
        return !modifiers.isDisjoint(with: [.control, .option, .command])
    }

    /// Keycap labels in the order macOS shows them: ⌃ ⌥ ⇧ ⌘, then the key.
    public var keycaps: [String] {
        let symbols: [(Modifiers, String)] = [(.control, "⌃"), (.option, "⌥"), (.shift, "⇧"), (.command, "⌘")]
        return symbols.filter { modifiers.contains($0.0) }.map(\.1) + [keyLabels[keyCode] ?? "Key \(keyCode)"]
    }

    /// The shortcut in words, for anyone who does not read ⌃ as Control: "Control + Option + V".
    public var name: String {
        let words: [(Modifiers, String)] = [(.control, "Control"), (.option, "Option"), (.shift, "Shift"), (.command, "Command")]
        let parts = words.filter { modifiers.contains($0.0) }.map(\.1) + [keyLabels[keyCode] ?? "Key \(keyCode)"]
        return parts.joined(separator: " + ")
    }
}

/// Captures the next shortcut the user presses.
public enum HotkeyRecorder {
    public enum Outcome: Equatable {
        case pending, cancelled, captured(Hotkey)
    }

    /// A key captures a shortcut when it comes with valid modifiers. Escape alone cancels.
    public static func keyPressed(_ keyCode: UInt16, held: Modifiers) -> Outcome {
        if keyCode == 53, held.isEmpty { return .cancelled }
        let hotkey = Hotkey(modifiers: held, keyCode: keyCode)
        return hotkey.isValid ? .captured(hotkey) : .pending
    }
}

/// Labels for the keys of an ANSI keyboard, by virtual key code.
private let keyLabels: [UInt16: String] = [
    0: "A", 1: "S", 2: "D", 3: "F", 4: "H", 5: "G", 6: "Z", 7: "X", 8: "C", 9: "V", 11: "B", 12: "Q",
    13: "W", 14: "E", 15: "R", 16: "Y", 17: "T", 18: "1", 19: "2", 20: "3", 21: "4", 22: "6", 23: "5",
    24: "=", 25: "9", 26: "7", 27: "-", 28: "8", 29: "0", 30: "]", 31: "O", 32: "U", 33: "[", 34: "I",
    35: "P", 36: "Return", 37: "L", 38: "J", 39: "'", 40: "K", 41: ";", 42: "\\", 43: ",", 44: "/",
    45: "N", 46: "M", 47: ".", 48: "Tab", 49: "Space", 50: "`", 51: "Delete", 53: "Esc",
    96: "F5", 97: "F6", 98: "F7", 99: "F3", 100: "F8", 101: "F9", 103: "F11", 109: "F10", 111: "F12",
    118: "F4", 120: "F2", 122: "F1", 123: "←", 124: "→", 125: "↓", 126: "↑",
```

```swift
import Carbon.HIToolbox
import Foundation
import VassagoEngine

/// Registers the shortcut with macOS. This needs no permission and no key hook.
final class GlobalHotkey {
    /// Called on the main thread when the shortcut is pressed.
    var onPress: () -> Void = {}

    private var registration: EventHotKeyRef?

    init() {
        var pressed = EventTypeSpec(eventClass: OSType(kEventClassKeyboard), eventKind: UInt32(kEventHotKeyPressed))
        // The dispatcher target also delivers the press while a menu is open.
        InstallEventHandler(
            GetEventDispatcherTarget(),
            { _, _, context in

        unregister()
        var modifiers = 0
        if hotkey.modifiers.contains(.control) { modifiers |= controlKey }
        if hotkey.modifiers.contains(.option) { modifiers |= optionKey }
        if hotkey.modifiers.contains(.shift) { modifiers |= shiftKey }
        if hotkey.modifiers.contains(.command) { modifiers |= cmdKey }
        let id = EventHotKeyID(signature: 0x5641_5353, id: 1)
        let status = RegisterEventHotKey(
            UInt32(hotkey.keyCode), UInt32(modifiers), id, GetEventDispatcherTarget(), 0, &registration)
        return status == noErr
    }

    func unregister() {
        if let registration { UnregisterEventHotKey(registration) }
        registration = nil
    }
```

```swift
/// One recorded copy. Its data is on disk; this is what the list needs to draw it.
public struct Clip: Codable, Equatable {
    public enum Kind: String, Codable {
        case text, image, files
    }

    /// Names the clip's files on disk.
    public let id: String
    public let kind: Kind
    /// The line the list shows.
    public let title: String
    /// Size of the clip's data.
    public let bytes: Int
    /// Equal digests mean equal content.
    public let digest: String

    public init(id: String, kind: Kind, title: String, bytes: Int, digest: String) {
        self.id = id
        self.kind = kind
        self.title = title
        self.bytes = bytes
        self.digest = digest
    }
}

/// The clips, newest first, held to a count and a total size.
public struct History {
    public private(set) var clips: [Clip]
    private let maxCount: Int
    private let maxBytes: Int

    public init(clips: [Clip] = [], maxCount: Int = 100, maxBytes: Int = 200_000_000) {
        self.clips = clips
        self.maxCount = maxCount
        self.maxBytes = maxBytes
    }

    /// Puts the clip on top. Returns the clips it pushed out, whose files are to be deleted:
    /// an older copy of the same content, then the oldest clips over a limit.
    public mutating func add(_ clip: Clip) -> [Clip] {
        var dropped = clips.filter { $0.digest == clip.digest }
        clips.removeAll { $0.digest == clip.digest }
        clips.insert(clip, at: 0)
        // The clip just added stays, whatever its size.
        while clips.count > 1, clips.count > maxCount || clips.reduce(0, { $0 + $1.bytes }) > maxBytes {
            dropped.append(clips.removeLast())
        }
        return dropped
    }

    public mutating func remove(id: String) -> Clip? {
        guard let index = clips.firstIndex(where: { $0.id == id }) else { return nil }
        return clips.remove(at: index)
    }

    public mutating func removeAll() -> [Clip] {
        defer { clips = [] }
        return clips
    }
}

/// The line the list shows for a text clip: its first line that is not empty, with each run of
/// whitespace as one space, at most 60 characters.
public func title(forText text: String) -> String {
    let line = text.split(whereSeparator: \.isNewline)
        .map { $0.split(whereSeparator: \.isWhitespace).joined(separator: " ") }
        .first { !$0.isEmpty } ?? ""
    return line.count > 60 ? String(line.prefix(59)) + "…" : line
}

/// What to keep at launch. A clip stays when its data file `<id>.plist` is in `files`, the names
/// found in the clips folder. `strays` are the names that belong to no kept clip, to be deleted.
public func reconcile(index: [Clip], files: Set<String>) -> (clips: [Clip], strays: [String]) {
    let clips = index.filter { files.contains($0.id + ".plist") }
    let owned = Set(clips.flatMap { [$0.id + ".plist", $0.id + ".png"] })
    return (clips, files.subtracting(owned).sorted())
}
```

```swift
import CryptoKit
import Foundation
import VassagoEngine

/// A clip's data as it sat on the clipboard: for each clipboard item, its types and their data.
typealias Payload = [[String: Data]]

/// The files under ~/Library/Application Support/Vassago. Used only on the clipboard queue,
/// apart from `thumbnail(of:)`, which only builds a path.
final class Store {
    private static let clips = FileManager.default
        .urls(for: .applicationSupportDirectory, in: .userDomainMask)[0]
        .appendingPathComponent("Vassago/clips", isDirectory: true)
    private static let index = clips.deletingLastPathComponent().appendingPathComponent("index.json")

    private let files = FileManager.default

    init() {
        try? files.createDirectory(at: Self.clips, withIntermediateDirectories: true)
        // Only this account may read what was copied.
        try? files.setAttributes([.posixPermissions: 0o700], ofItemAtPath: Self.clips.deletingLastPathComponent().path)
    }

    static func thumbnail(of id: String) -> URL {
        clips.appendingPathComponent(id + ".png")
    }

    private static func data(of id: String) -> URL {
        clips.appendingPathComponent(id + ".plist")
    }

    /// The clips kept from the last run, less those whose data is gone. Files that no clip names are deleted.
    func load() -> [Clip] {
        let index = (try? Data(contentsOf: Self.index)).flatMap { try? JSONDecoder().decode([Clip].self, from: $0) } ?? []
        // A folder that cannot be listed is left alone, not taken for empty.
        guard let names = try? files.contentsOfDirectory(atPath: Self.clips.path) else { return index }
        let kept = reconcile(index: index, files: Set(names))
        for name in kept.strays {
            try? files.removeItem(at: Self.clips.appendingPathComponent(name))
        }
        return kept.clips
    }

    /// False when the data could not be written. Nothing is left behind then.
    func write(_ payload: Payload, thumbnail: Data?, id: String) -> Bool {
        do {
            let data = try PropertyListSerialization.data(fromPropertyList: payload, format: .binary, options: 0)
            try data.write(to: Self.data(of: id), options: .atomic)
            try thumbnail?.write(to: Self.thumbnail(of: id), options: .atomic)
            return true
        } catch {
            delete([id])
            return false
        }
    }

    func save(_ clips: [Clip]) {
        guard let data = try? JSONEncoder().encode(clips) else { return }
        try? data.write(to: Self.index, options: .atomic)
    }

    func delete(_ ids: [String]) {
        for id in ids {
            try? files.removeItem(at: Self.data(of: id))
            try? files.removeItem(at: Self.thumbnail(of: id))
        }
    }

    func payload(of id: String) -> Payload? {
        guard let data = try? Data(contentsOf: Self.data(of: id)) else { return nil }
        return (try? PropertyListSerialization.propertyList(from: data, format: nil)) as? Payload
    }

    /// The same for two copies of the same content, whatever order their types came in.
    static func digest(of payload: Payload) -> String {
        var hash = SHA256()
        for item in payload {
            for type in item.keys.sorted() {
                hash.update(data: Data(type.utf8))
                hash.update(data: item[type]!)
            }
        }
        return hash.finalize().map { String(format: "%02x", $0) }.joined()
    }
}
```

```swift
import AppKit
import ImageIO

/// Watches the clipboard, records what is copied, and puts a clip back.
/// Everything that touches the clipboard or the disk runs on one background queue, never on the main thread.
final class Clipboard {
    /// What macOS lets Vassago do with the clipboard when nobody pressed Paste.
    enum Access {
        case allowed, neverAsked, notAllowed
    }

    /// Privacy & Security → Paste from Other Apps.
    static let settingsPane = URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Pasteboard")!

    /// macOS 15.4 and later ask the user before an app reads the clipboard on its own.
    static var access: Access {
        guard #available(macOS 15.4, *) else { return .allowed }
        switch NSPasteboard.general.accessBehavior {
        case .alwaysAllow: return .allowed
        case .default: return .neverAsked
        default: return .notAllowed
        }
    }

    /// Called on the main thread with the clips, newest first, whenever they change.
    var onChange: ([Clip]) -> Void = { _ in }

    private static let own = NSPasteboard.PasteboardType("com.quyennguyenvu.vassago.own")
    /// Marked secret or short-lived by the copying app, written by Vassago itself, or still on another device.
    private static let skipped: Set = [
        "org.nspasteboard.ConcealedType", "org.nspasteboard.TransientType", "org.nspasteboard.AutoGeneratedType",
        "com.apple.is-remote-clipboard", own.rawValue,
    ]
    private static let largest = 20_000_000

    private let queue = DispatchQueue(label: "com.quyennguyenvu.vassago.clipboard", qos: .utility)
    private let pasteboard = NSPasteboard.general
    private let store = Store()
    private var history = History()
    private var timer: DispatchSourceTimer?
    private var seen = 0
    private var recording = false

    /// Loads the saved clips and starts watching.
    func start() {
        queue.async { [self] in
            history = History(clips: store.load())
            publish()
            // What is already on the clipboard is not recorded.
            seen = pasteboard.changeCount
            let timer = DispatchSource.makeTimerSource(queue: queue)
            timer.schedule(deadline: .now() + 0.3, repeating: 0.3)
            timer.setEventHandler { [weak self] in self?.poll() }
            timer.resume()
            self.timer = timer
        }
    }

    /// Whether a change is read: the history is switched on and macOS allows the read.
    func setRecording(_ on: Bool) {
        queue.async { self.recording = on }
    }

    /// One read, made so that macOS shows its prompt and lists Vassago in System Settings.
    func ask() {
        queue.async { _ = self.pasteboard.string(forType: .string) }
    }

    /// Puts the clip back on the clipboard, then calls `done` on the main thread: false when its data is gone.
    func put(_ clip: Clip, done: @escaping (Bool) -> Void) {
        queue.async { [self] in
            guard let payload = store.payload(of: clip.id) else {
                drop(history.remove(id: clip.id).map { [$0] } ?? [])
                DispatchQueue.main.async { done(false) }
                return
            }
            let items = payload.map { types -> NSPasteboardItem in
                let item = NSPasteboardItem()
                for (type, data) in types {
                    item.setData(data, forType: NSPasteboard.PasteboardType(type))
                }
                return item
            }
            // The marker keeps the watcher from recording this write, so the list keeps its order.
            items.first?.setString("1", forType: Self.own)
            pasteboard.clearContents()
            pasteboard.writeObjects(items)
            DispatchQueue.main.async { done(true) }
        }
    }

    func delete(_ clip: Clip) {
        queue.async { [self] in drop(history.remove(id: clip.id).map { [$0] } ?? []) }
    }

    func clear() {
        queue.async { [self] in drop(history.removeAll()) }
    }

    /// Presses Command+V in the app in front. macOS ignores it unless Accessibility is granted.
    static func pressPaste() {
        let source = CGEventSource(stateID: .combinedSessionState)
        for keyDown in [true, false] {
            let event = CGEvent(keyboardEventSource: source, virtualKey: 9, keyDown: keyDown)
            event?.flags = .maskCommand
            event?.post(tap: .cgSessionEventTap)
        }
    }

    private func poll() {
        let count = pasteboard.changeCount
        guard count != seen else { return }
        guard recording else {
            seen = count
            return
        }
        // A copying app clears the clipboard, which moves the counter, and writes a moment later
        // without moving it again. So an empty clipboard is looked at again on the next tick.
        guard let types = pasteboard.types, !types.isEmpty else { return }
        seen = count
        guard let (payload, clip, thumbnail) = read() else { return }
        // Data first and the index after, so the index never names data that is not there.
        guard store.write(payload, thumbnail: thumbnail, id: clip.id) else { return }
        drop(history.add(clip))
    }

    /// Saves the index, deletes the files of the clips that left, and tells the main thread.
    private func drop(_ gone: [Clip]) {
        store.save(history.clips)
        store.delete(gone.map(\.id))
        publish()
    }

    private func publish() {
        let clips = history.clips
        DispatchQueue.main.async { self.onChange(clips) }
    }

    /// What is on the clipboard as a clip to keep, or nil when it is to be skipped.
    private func read() -> (Payload, Clip, Data?)? {
        guard !(pasteboard.types ?? []).contains(where: { Self.skipped.contains($0.rawValue) }) else { return nil }
        var payload: Payload = []
        var files: [URL] = []
        var text: String?
        var image: Data?
        for item in pasteboard.pasteboardItems ?? [] {
            var kept: [String: Data] = [:]
            let string = item.string(forType: .string)
            let hasText = string.map { !$0.allSatisfy(\.isWhitespace) } ?? false
            if let reference = item.data(forType: .fileURL), let url = URL(dataRepresentation: reference, relativeTo: nil) {
                // Finder copies a reference by file id; the path form has the file's name.
                files.append((url as NSURL).filePathURL ?? url)
                kept[NSPasteboard.PasteboardType.fileURL.rawValue] = reference
                if hasText { kept[NSPasteboard.PasteboardType.string.rawValue] = item.data(forType: .string) }
            } else {
                if hasText {
                    for type in [.string, .rtf, .html] as [NSPasteboard.PasteboardType] {
                        kept[type.rawValue] = item.data(forType: type)
                    }
                    text = text ?? string
                }
                if let png = item.data(forType: .png) ?? item.data(forType: .tiff).flatMap(Self.converted) {
                    kept[NSPasteboard.PasteboardType.png.rawValue] = png
                    image = image ?? png
                }
            }
            if !kept.isEmpty { payload.append(kept) }
        }
        let bytes = payload.reduce(0) { $0 + $1.values.reduce(0) { $0 + $1.count } }
        guard !payload.isEmpty, bytes <= Self.largest else { return nil }

        let kind: Clip.Kind
        let title: String
        var thumbnail: Data?
        if let first = files.first {
            kind = .files
            title = files.count == 1 ? first.lastPathComponent : "\(first.lastPathComponent) and \(files.count - 1) more"
            thumbnail = Self.icon(of: first)
        } else if let text {
            // Office apps add a picture of the text they copy, so text decides before an image does.
            kind = .text
            title = VassagoEngine.title(forText: text)
        } else {
            guard let image, let source = CGImageSourceCreateWithData(image as CFData, nil),
                  let properties = CGImageSourceCopyPropertiesAtIndex(source, 0, nil) as? [CFString: Any],
                  let width = properties[kCGImagePropertyPixelWidth] as? Int,
                  let height = properties[kCGImagePropertyPixelHeight] as? Int else { return nil }
            kind = .image
            title = "Image \(width) × \(height)"
            // At most 128 pixels on its longer side.
            let options = [kCGImageSourceCreateThumbnailFromImageAlways: true, kCGImageSourceThumbnailMaxPixelSize: 128] as [CFString: Any]
            thumbnail = CGImageSourceCreateThumbnailAtIndex(source, 0, options as CFDictionary).flatMap(Self.encoded)
        }
        let clip = Clip(id: UUID().uuidString, kind: kind, title: title, bytes: bytes, digest: Store.digest(of: payload))
        return (payload, clip, thumbnail)
    }

    /// PNG data for an image in another format, or nil if it cannot be read.
    private static func converted(_ data: Data) -> Data? {
        guard let source = CGImageSourceCreateWithData(data as CFData, nil) else { return nil }
        return CGImageSourceCreateImageAtIndex(source, 0, nil).flatMap(encoded)
    }

    private static func encoded(_ image: CGImage) -> Data? {
        let data = NSMutableData()
        guard let destination = CGImageDestinationCreateWithData(data, UTType.png.identifier as CFString, 1, nil) else { return nil }
        CGImageDestinationAddImage(destination, image, nil)
        return CGImageDestinationFinalize(destination) ? data as Data : nil
    }

    /// The file's Finder icon, 64 pixels square.
    private static func icon(of file: URL) -> Data? {
        var frame = CGRect(x: 0, y: 0, width: 64, height: 64)
        return NSWorkspace.shared.icon(forFile: file.path).cgImage(forProposedRect: &frame, context: nil, hints: nil).flatMap(encoded)
    }
}
```

```swift
        if !model.trusted { add("Grant Accessibility to paste directly…", #selector(openAccessibilitySettings), to: menu) }
        if menu.numberOfItems > before { menu.addItem(.separator()) }
    }

    /// The newest `limit` clips. Picking one pastes it into the app in front.
    func addClips(to menu: NSMenu, limit: Int) {

            // With no action the row is disabled.

            let item = add(clip.title, #selector(pick(_:)), to: menu)
            // The nine newest are one digit away.
            if index < 9 {
                item.keyEquivalent = String(index + 1)
                item.keyEquivalentModifierMask = []
            }
            item.representedObject = clip.id
            item.image = model.thumbnail(of: clip)
        }
    }

    @discardableResult
    private func add(_ title: String, _ action: Selector, to menu: NSMenu) -> NSMenuItem {
        let item = menu.addItem(withTitle: title, action: action, keyEquivalent: "")
        item.target = self
        return item
    }

        guard let clip = model.clips.first(where: { $0.id == item.representedObject as? String }) else { return }
        model.pick(clip, paste: true)
    }

    @objc private func openPanel() {
        model.openPanel()
    }

    @objc private func openAccessibilitySettings() {
        model.openAccessibilitySettings()
    }
```

```swift
import AppKit
import Combine
import ServiceManagement
import VassagoEngine

/// The settings, state and actions that the menu bar item, the list and the panel share.
final class AppModel: ObservableObject {
    @Published var keepsHistory: Bool {
        didSet {
            UserDefaults.standard.set(keepsHistory, forKey: "keepsHistory")
            if keepsHistory, access == .neverAsked { clipboard.ask() }
            refreshRecording()
            stateChanged()
        }
    }

    @Published private(set) var hotkey: Hotkey {
        didSet {
            UserDefaults.standard.set(Int(hotkey.modifiers.rawValue), forKey: "hotkeyModifiers")
            UserDefaults.standard.set(Int(hotkey.keyCode), forKey: "hotkeyKeyCode")
        }
    }

    /// The history, newest first.
    @Published private(set) var clips: [Clip] = []

    @Published private(set) var access = Clipboard.access {
        didSet {
            refreshRecording()
            stateChanged()
        }
    }

    /// Accessibility is granted, so a pick can press Command+V.
    @Published private(set) var trusted = AXIsProcessTrusted()
    /// The next shortcut pressed in the panel becomes the hotkey.
    @Published private(set) var recording = false
    /// macOS would not register the shortcut just recorded.
    @Published private(set) var hotkeyRefused = false
    @Published private(set) var launchAtLogin = SMAppService.mainApp.status == .enabled
    /// A release newer than the running app, once a check has found one.
    @Published private(set) var availableVersion: Version? {
        didSet { stateChanged() }
    }

    /// The clip a click in the panel has just copied, for a moment.
    @Published private(set) var copied: String?

    /// Called on the main thread when what the menu bar item shows has changed.
    var stateChanged: () -> Void = {}
    var onHotkey: () -> Void = {}
    var openPanel: () -> Void = {}

    /// The history is switched on, but macOS does not let Vassago read the clipboard.
    var cannotRecord: Bool {
        keepsHistory && access != .allowed
    }

    private let defaults = UserDefaults.standard
    private let clipboard = Clipboard()
    private let globalHotkey = GlobalHotkey()
    private var recorder: Any?
    private var thumbnails: [String: NSImage] = [:]

    init() {
        let defaults = UserDefaults.standard
        defaults.register(defaults: ["keepsHistory": true])
        keepsHistory = defaults.bool(forKey: "keepsHistory")
        hotkey = Self.storedHotkey(in: defaults)
    }

    /// Loads the history, registers the hotkey, asks for the permissions once, and starts watching both.
    func start() {
        clipboard.onChange = { [weak self] clips in
            guard let self else { return }
            self.clips = clips
            let kept = Set(clips.map(\.id))
            self.thumbnails = self.thumbnails.filter { kept.contains($0.key) }
        }
        clipboard.start()
        globalHotkey.onPress = { [weak self] in self?.onHotkey() }
        hotkeyRefused = !globalHotkey.register(hotkey)
        requestAccessibility()
        if keepsHistory, access == .neverAsked { clipboard.ask() }
        refreshRecording()
        checkForUpdatesIfDue()
        Timer.scheduledTimer(withTimeInterval: 2, repeats: true) { [weak self] _ in self?.tick() }
    }

    /// Both permissions can change in System Settings at any time, so they are read again here.
    private func tick() {
        let trusted = AXIsProcessTrusted()
        if trusted != self.trusted { self.trusted = trusted }
        let access = Clipboard.access
        if access != self.access { self.access = access }
        checkForUpdatesIfDue()
    }

    private func refreshRecording() {
        clipboard.setRecording(keepsHistory && access == .allowed)
    }

    // MARK: The history

    /// Puts the clip on the clipboard. From a list outside the panel it is then pasted into the app in front.
    func pick(_ clip: Clip, paste: Bool) {
        clipboard.put(clip) { [weak self] found in
            guard found else {
                NSSound.beep()
                return
            }
            if paste {
                if AXIsProcessTrusted() { Clipboard.pressPaste() }
            } else {
                self?.flash(clip.id)
            }
        }
    }

    private func flash(_ id: String) {
        copied = id
        DispatchQueue.main.asyncAfter(deadline: .now() + 0.6) { [weak self] in
            if self?.copied == id { self?.copied = nil }
        }

        clipboard.delete(clip)
    }

    func clearHistory() {
        guard !clips.isEmpty else { return }
        let alert = NSAlert()
        alert.messageText = "Clear the clipboard history?"
        alert.informativeText = clips.count == 1 ? "The clip is deleted. This cannot be undone." : "All \(clips.count) clips are deleted. This cannot be undone."
        alert.addButton(withTitle: "Clear")
        alert.addButton(withTitle: "Cancel")
        NSApp.activate(ignoringOtherApps: true)
        if alert.runModal() == .alertFirstButtonReturn { clipboard.clear() }
    }

    /// The picture in front of an image or files row, sized to fit 64 × 32 points.
    func thumbnail(of clip: Clip) -> NSImage? {
        guard clip.kind != .text else { return nil }
        if let cached = thumbnails[clip.id] { return cached }
        guard let image = NSImage(contentsOf: Store.thumbnail(of: clip.id)), image.size.width > 0, image.size.height > 0 else { return nil }
        let scale = min(64 / image.size.width, 32 / image.size.height, 1)
        image.size = NSSize(width: image.size.width * scale, height: image.size.height * scale)
        thumbnails[clip.id] = image
        return image
    }

    // MARK: The hotkey

    /// The next shortcut pressed in the panel becomes the hotkey. Escape, or leaving the panel, cancels.
    func record() {
        guard !recording else { return }
        recording = true
        hotkeyRefused = false
        // Unregistered meanwhile, so that pressing the current shortcut can be captured too.
        globalHotkey.unregister()
        recorder = NSEvent.addLocalMonitorForEvents(matching: .keyDown) { [weak self] event in
            guard let self else { return event }
            switch HotkeyRecorder.keyPressed(event.keyCode, held: Self.modifiers(event.modifierFlags)) {
            case .pending: return event
            case .cancelled: self.finishRecording(nil)
            case .captured(let hotkey): self.finishRecording(hotkey)
            }
            return nil
        }
    }

    func cancelRecording() {
        if recording { finishRecording(nil) }
    }

    private func finishRecording(_ captured: Hotkey?) {
        if let recorder { NSEvent.removeMonitor(recorder) }
        recorder = nil
        recording = false
        if let captured, globalHotkey.register(captured) {
            hotkey = captured
        } else {
            // Cancelled, or refused by macOS: the previous shortcut stays.
            hotkeyRefused = captured != nil
            _ = globalHotkey.register(hotkey)
        }
    }

    private static func modifiers(_ flags: NSEvent.ModifierFlags) -> Modifiers {
        var held: Modifiers = []
        if flags.contains(.control) { held.insert(.control) }
        if flags.contains(.option) { held.insert(.option) }
        if flags.contains(.shift) { held.insert(.shift) }
        if flags.contains(.command) { held.insert(.command) }
        return held
    }

    private static func storedHotkey(in defaults: UserDefaults) -> Hotkey {
        guard defaults.object(forKey: "hotkeyKeyCode") != nil else { return .standard }
        let stored = Hotkey(
            modifiers: Modifiers(rawValue: UInt8(truncatingIfNeeded: defaults.integer(forKey: "hotkeyModifiers"))),
            keyCode: UInt16(truncatingIfNeeded: defaults.integer(forKey: "hotkeyKeyCode")))
        return stored.isValid ? stored : .standard
    }

    // MARK: Permissions

    /// Opens the Settings pane where the user picks Always Allow for Vassago.
    func allowClipboardAccess() {
        // macOS lists Vassago there only after it has asked once.
        if access == .neverAsked { clipboard.ask() }
        NSWorkspace.shared.open(Clipboard.settingsPane)
    }

    func openAccessibilitySettings() {
        NSWorkspace.shared.open(URL(string: "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility")!)
    }

    /// Clears a grant left behind by a build from another signer, which macOS still lists as
    /// switched on but no longer honours, then asks again.
    func resetPermission() {
        let reset = Process()
        reset.executableURL = URL(fileURLWithPath: "/usr/bin/tccutil")
        reset.arguments = ["reset", "Accessibility", Bundle.main.bundleIdentifier ?? "com.quyennguyenvu.vassago"]
        var cleared = false
        do {
            try reset.run()
            reset.waitUntilExit()
            cleared = reset.terminationStatus == 0
        } catch {
            cleared = false
        }
        if !cleared {
            let alert = NSAlert()
            alert.messageText = "Couldn't reset the permission"
            alert.informativeText = "In System Settings → Privacy & Security → Accessibility, select Vassago, remove it with the − button, then grant it again."
            alert.runModal()
        }
        requestAccessibility()
        openAccessibilitySettings()
    }

    /// Shows the system prompt if Accessibility is not granted, and lists Vassago in System Settings.
    private func requestAccessibility() {
        let prompt = [kAXTrustedCheckOptionPrompt.takeUnretainedValue() as String: true] as CFDictionary
        AXIsProcessTrustedWithOptions(prompt)
    }

    // MARK: Launch at login and updates

    func setLaunchAtLogin(_ on: Bool) {
        do {
            if on {
                try SMAppService.mainApp.register()
            } else {
                try SMAppService.mainApp.unregister()
            }
        } catch {
            NSAlert(error: error).runModal()
        }
        launchAtLogin = SMAppService.mainApp.status == .enabled
    }

    /// A check the user asked for: always answered with an alert.
    func checkForUpdates() {
        UpdateCheck.latest { [weak self] latest, _ in
            self?.note(latest)
            UpdateCheck.report(latest: latest)
        }
    }

    func openReleasePage() {
        guard let availableVersion else { return }
        NSWorkspace.shared.open(UpdateCheck.releasePage(for: availableVersion))
    }

    /// The quiet daily check. It only switches the update dot and the "available" lines on or off.
    private func checkForUpdatesIfDue() {
        let now = Date().timeIntervalSince1970
        guard now >= defaults.double(forKey: "nextUpdateCheck") else { return }
        // Booked an hour ahead first, so a check that gets no answer is retried then, not on every tick.
        defaults.set(now + 3600, forKey: "nextUpdateCheck")
        UpdateCheck.latest { [weak self] latest, answered in
            self?.note(latest)
            if answered { self?.defaults.set(Date().timeIntervalSince1970 + 86_400, forKey: "nextUpdateCheck") }
        }
    }

    /// A check that named no version leaves what is already known alone.
    private func note(_ latest: Version?) {
        guard let latest, let current = UpdateCheck.current else { return }
        availableVersion = latest > current ? latest : nil
    }
```

```swift
/// The menu bar item, the Dock behaviour, and the rule that only the menu bar item can quit the app.
final class StatusMenu: NSObject, NSApplicationDelegate, NSMenuDelegate {
    private let model = AppModel()
    private lazy var panel = Panel(model: model)
    private lazy var historyMenu = HistoryMenu(model: model)
    private let statusItem = NSStatusBar.system.statusItem(withLength: NSStatusItem.variableLength)
    private var quitFromMenu = false

    func applicationDidFinishLaunching(_ notification: Notification) {
        let menu = NSMenu()
        menu.delegate = self
        statusItem.menu = menu
        statusItem.button?.imagePosition = .imageLeading
        NSApp.mainMenu = Self.mainMenu()

        model.stateChanged = { [weak self] in self?.refreshTitle() }
        model.onHotkey = { [weak self] in self?.historyMenu.popUp() }
        model.openPanel = { [weak self] in self?.panel.show() }
        model.start()
        refreshTitle()
        if model.cannotRecord || !model.trusted { panel.show() }
    }

    private func refreshTitle() {
        // The warning replaces the symbol while nothing can be recorded; the dot says a newer release is waiting.
        let symbol = NSImage(systemSymbolName: "doc.on.clipboard", accessibilityDescription: "Vassago")
        statusItem.button?.image = model.cannotRecord ? nil : symbol
        statusItem.button?.title = (model.cannotRecord ? "⚠" : "") + (model.availableVersion == nil ? "" : " •")
    }

    func menuNeedsUpdate(_ menu: NSMenu) {
        menu.removeAllItems()
        historyMenu.addPermissionRows(to: menu)
        if let version = model.availableVersion {
            add("Version \(version.text) Available…", #selector(openReleasePage), to: menu)
            menu.addItem(.separator())
        }
        historyMenu.addClips(to: menu, limit: 9)
        menu.addItem(.separator())
        add("Open Vassago…", #selector(openPanel), to: menu)
        add("Clear History…", #selector(clearHistory), to: menu)
        add("Check for Updates…", #selector(checkForUpdates), to: menu)
        menu.addItem(.separator())
        add("Quit Vassago", #selector(quit), to: menu)
    }

    private func add(_ title: String, _ action: Selector, to menu: NSMenu) {
        menu.addItem(withTitle: title, action: action, keyEquivalent: "").target = self
    }

    @objc private func openPanel() {
        panel.show()
    }

    @objc private func clearHistory() {
        model.clearHistory()
    }

    @objc private func checkForUpdates() {
        model.checkForUpdates()
    }

    @objc private func openReleasePage() {
        model.openReleasePage()
    }

    @objc private func quit() {
        quitFromMenu = true
        NSApp.terminate(nil)
    }

    // MARK: Dock and quitting

    func applicationShouldHandleReopen(_ sender: NSApplication, hasVisibleWindows flag: Bool) -> Bool {
        panel.show()
        return false
    }

    func applicationShouldTerminate(_ sender: NSApplication) -> NSApplication.TerminateReply {
        if quitFromMenu || Self.systemIsShuttingDown() { return .terminateNow }
        // The Dock's Quit, like any other request to quit, only puts the panel away.
        panel.close()
        return .terminateCancel
    }

    /// Logout, restart and shutdown must still be able to quit the app.
    private static func systemIsShuttingDown() -> Bool {
        let event = NSAppleEventManager.shared().currentAppleEvent
        guard let reason = event?.attributeDescriptor(forKeyword: AEKeyword(kAEQuitReason))?.enumCodeValue else { return false }
        let systemWide = [kAELogOut, kAEReallyLogOut, kAERestart, kAEShutDown, kAEShowRestartDialog, kAEShowShutdownDialog]
        return systemWide.map { OSType($0) }.contains(reason)
    }

    /// No Quit item on purpose.
    private static func mainMenu() -> NSMenu {
        let app = NSMenu()
        app.addItem(withTitle: "Hide Vassago", action: #selector(NSApplication.hide(_:)), keyEquivalent: "h")
        app.addItem(withTitle: "Close Panel", action: #selector(NSWindow.performClose(_:)), keyEquivalent: "w")
        // With no Quit item, ⌘Q would do nothing at all. An unlisted second shortcut makes it close the panel.
        let alsoClose = app.addItem(withTitle: "Close Panel", action: #selector(NSWindow.performClose(_:)), keyEquivalent: "q")
        alsoClose.isHidden = true
        alsoClose.allowsKeyEquivalentWhenHidden = true

        let main = NSMenu()
        let item = NSMenuItem()
        item.submenu = app
        main.addItem(item)
        return main
    }
```

````markdown
A clipboard history for macOS. Copy several things in one place, then paste each of them somewhere else without going back for the next one. A hotkey opens the history at the mouse pointer, and one more key pastes the item you pick. The idea comes from Ditto on Windows. Swift, no dependencies, local only: no account, no telemetry.

## Why Vassago

**Copy many, then paste many.** A page lists five order codes and each needs its own browser tab. Copy all five, then in each tab press ⌃⌥V (Control + Option + V) and a digit. No switching back for the next code.

**The list never takes your cursor.** It is an ordinary macOS menu, so the app you are pasting into keeps the keyboard focus and the paste lands where you were typing.

**Text, images and files.** Text keeps its formatting, screenshots show a thumbnail, and copied files paste as files. The history survives a restart.

**It skips secrets.** Anything a password manager marks as concealed, as KeePassXC and 1Password do, is never recorded.

**Small and local.** About 1,300 lines of Swift with no third-party code. The only network request Vassago ever makes asks GitHub for the latest release number, at most once a day and when you choose Check for Updates. Nothing you copy leaves your Mac.

In the Ars Goetia, Vassago is the prince "of the same nature as Agares" whose office is "to declare things past and to come, and to discover all things hid or lost".

## Install

Grab the `.dmg` from the [Releases page](https://github.com/quyennguyenvu/vassago/releases). One file runs on both Apple Silicon and Intel Macs, macOS 13 or newer.

Vassago isn't signed with a paid Apple certificate (it's a personal project), so macOS blocks the **first** launch with a warning. The warning only means the developer didn't buy a certificate. Allow it once and it never appears again.

1. Open the `.dmg` and drag **Vassago** onto **Applications**.
2. Open **Vassago** from Applications. macOS says **"Apple could not verify 'Vassago' is free of malware"**.
3. **Click "Done", not "Move to Trash".** Move to Trash is the highlighted button, and it deletes the app.
4. Allow it once, using either method below, then open Vassago again.
5. Switch Vassago on under **System Settings → Privacy & Security → Accessibility**. Vassago opens its panel with a button that takes you there. It needs this permission to press Command+V for you when you pick a clip.

**Without Terminal.** Open **System Settings → Privacy & Security** and scroll to the **Security** section. Click **Open Anyway** and confirm with Touch ID or your password.

**With Terminal.**

xattr -dr com.apple.quarantine /Applications/Vassago.app
```

| Permission | Where | Why |
| --- | --- | --- |

### Updating

Vassago tells you when a newer version exists. Once a day it asks GitHub for the latest release; if there is one, a dot appears on the menu bar item, the menu gains a **Version … Available…** item, and the panel shows a **Get …** button. Each opens the release page. Vassago never downloads or installs anything itself.

Replace the app in Applications with the newer version. Every release is signed with the same certificate, so the Accessibility permission carries over.

## Using it

- **Open the list** with ⌃⌥V. Digits 1 to 9 paste the nine newest clips; the arrow keys and Enter, or a click, reach the rest. Esc closes it.

- **Open the panel** from the menu bar item, or by opening Vassago again from Launchpad or Spotlight. It holds the on/off switch, the hotkey, the whole history, Launch at login and Check for Updates. A click on a row copies it back; the × deletes it.
- **Change the hotkey** with **Record…** in the panel. It must include Control, Option or Command.
- **Vassago lives in the menu bar.** Its Dock icon is there only while the panel is open.
- **Closing the panel does not quit Vassago**, and neither do ⌘Q or the Dock's Quit. To quit, click the menu bar item and choose **Quit Vassago**.

### Good to know

- **The history is kept on your disk, not encrypted,** under `~/Library/Application Support/Vassago`, readable only by your account. A password copied from an app that does not mark it as concealed is saved like any other text. Delete it with the × in the panel, or clear everything with **Clear All**.
- **100 clips or 200 MB**, whichever comes first. The oldest clips make room for new ones. A single copy over 20 MB is not kept.
- **Pasting does not reorder the list,** so the numbers stay put while you work through a run of clips.
- **Copying the same thing again** moves it to the top instead of adding a second row.
- **Files are remembered by location.** If a file has moved or been deleted, its clip pastes nothing.
- **Images are kept as PNG.**
- **What you copy on your iPhone** and paste on the Mac through Universal Clipboard is not recorded.
- **Two copies within a third of a second** record only the second.

### If something looks off

- **`⚠` in the menu bar:** Vassago is not allowed to read the clipboard, so nothing is being recorded. Open the panel and press **Allow Clipboard Access…**, then choose **Always Allow** for Vassago.
- **Picking a clip copies but does not paste:** Accessibility is missing. Open the panel and press **Grant Accessibility…**. If Vassago is already switched on there, macOS is holding a permission from an older build: press **Reset Permission** instead, then switch it on again.
- **The hotkey does nothing:** another app may own that shortcut. Record a different one in the panel.

## Developing

You need macOS 13 or newer, a Swift 6 toolchain (the Command Line Tools are enough, no Xcode), and `librsvg` for the icon (`brew install librsvg`).

```sh
bash scripts/test.sh             # run the tests
bash scripts/bundle.sh install   # build, sign, copy to /Applications and launch
```

Builds are signed with the self-signed "Agares Dev" certificate, the one [Agares](https://github.com/quyennguyenvu/agares) uses, so the Accessibility permission survives every rebuild. Create it once with `scripts/make-cert.sh` from the Agares repository. Releases use that same certificate; a certificate you create yourself is a different signer, so your builds and the released ones do not share a permission.

### Releasing

```sh
scripts/release.sh 0.2.0            # test, bump Resources/Info.plist, commit, tag, push
scripts/release.sh 0.2.0 --dry-run  # show what it would do
```

Pushing the `v0.2.0` tag starts `.github/workflows/release.yml`, which re-runs the tests, builds a universal app, signs it with the "Agares Dev" certificate, packages `Vassago-0.2.0.dmg`, attaches a provenance attestation and `SHA256SUMS.txt`, and publishes the GitHub release with `.github/release-body.md` on top of the generated notes. Tags are always `v` plus three numbers; the in-app update check ignores anything else.

The workflow reads the certificate from two repository secrets, `SIGNING_P12_BASE64` and `SIGNING_P12_PASSWORD`, set once under **Settings → Secrets and variables → Actions**. They hold the same values as in the Agares repository, whose README shows how to export them. The workflow refuses to publish a build whose signer is not that exact certificate.
````
